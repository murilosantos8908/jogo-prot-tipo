# O Coração de Sangue — ambientes do prólogo

Demonstração web dos seis ambientes 3D do prólogo, feita com Next.js e Three.js. A interface serve para inspecionar cenários; não inclui personagens ou mecânicas de jogo.

## Executar localmente

1. Instale Node.js 20.9 ou superior.
2. No diretório do projeto, execute `npm install`.
3. Execute `npm run dev` e abra `http://localhost:3000`.

Para gerar e iniciar a versão de produção, use `npm run build` e depois `npm start`.

## Controles

- Arraste para orbitar a câmera.
- Role para aproximar ou afastar.
- Arraste com o botão direito para deslocar o enquadramento.
- Use a barra superior para trocar de cena. A cena 6 oferece uma alternância de iluminação anterior/manifestação.

As cenas 2–4 compartilham a mesma planta da residência. As cenas 5–6 compartilham a mesma estrada e clareira. A cena 6 altera apenas o estado de luz/atmosfera.
